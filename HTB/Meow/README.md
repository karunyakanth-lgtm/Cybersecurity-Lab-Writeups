# Hack The Box — Meow

Beginner HTB machine focused on reconnaissance, Telnet enumeration, remote access, and Linux command-line enumeration.

See the main repository README for the complete writeup and screenshots.

## Quick Reference

```bash
ping -c 4 <TARGET_IP>
nmap -sC -sV <TARGET_IP>
telnet <TARGET_IP> 23
whoami
uname -a
pwd
ls
cat <FLAG_FILE>
```
